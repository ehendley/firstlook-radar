# 初见雷达

体验网站：https://ehendley.github.io/firstlook-radar/

上传单人照片，生成六维视觉风格报告、具体亮点、拍照建议和分享卡。当前模型为阿里云百炼北京地域 qwen3-vl-plus，Key 仅保存在后端。

当前 Cloudflare 后端已通过官方示例图的真实模型请求（约33秒），但大陆无 VPN 手机网络出现连接失败，尚不能保证该网络可用。

本次修复：连接检测由6秒改为15秒；提供“重新连接”，网络恢复或回到页面时重新检测，保留已选照片。恢复检测只请求配置与健康检查，不自动提交照片，不重复调用模型。若后端域名持续不可达，需要更换可访问的后端地址。

完整开发源码、测试和阿里云FC测试部署说明见 full-source.zip。FC后端版本已准备为可选方案，尚未开通或部署；其实际使用需账号持有人确认服务协议、按量费用并配置密钥。FC默认域名仅供小范围测试，正式公开网站需自有域名及适用的备案。

照片与报告仅在浏览器和请求内存处理，本站不建照片数据库。分数描述这张照片的视觉呈现，不是颜值、人格测评或陌生人的实际意见。
